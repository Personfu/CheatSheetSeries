# PersonFu Cheatsheet Style Guide

Cheatsheets should be fast, visual, source-aware, and safe.

## Format

- Title: specific and searchable.
- Scope: who it is for and what it covers.
- Quick map: 5-9 bullets maximum.
- Commands: lab-safe or defensive only.
- Warnings: common mistakes and unsafe boundaries.
- Report output: what artifact the reader should produce.

## Visual style

- Dark background.
- Cyan/magenta/amber accents.
- Monospace labels.
- Dense but readable tables.
- Small diagrams where they clarify flow.

## Required footer

Every security cheatsheet should end with: owned systems, written permission, CTF/lab scope, or defensive validation only.
